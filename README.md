# Java Programming – MOOC Helsinki

## Overview

This repository contains my solutions for the **Java Programming I & II** courses provided by the University of Helsinki (MOOC.fi).

The course offers a comprehensive introduction to Java, covering fundamental programming concepts, object-oriented programming, and advanced topics such as data structures, streams, and graphical user interfaces.

All solutions are implemented independently, with a focus on writing clean, readable, and well-structured code.

## Course Content

### Java Programming I

* Part 1: Basics of programming (printing, input, variables, conditionals)
* Part 2: Repetition and methods
* Part 3: Lists, arrays, and strings
* Part 4: Introduction to object-oriented programming and file handling
* Part 5: Advanced OOP concepts and references
* Part 6: Complex objects, program structure, and testing
* Part 7: Algorithms, programming paradigms, and larger exercises

### Java Programming II

* Part 8: Hash maps and data grouping
* Part 9: Inheritance, interfaces, and polymorphism
* Part 10: Streams, lambda expressions, and collections
* Part 11: Exceptions, files, and packages
* Part 12: Generics, data structures, and randomness
* Part 13: Graphical user interfaces (JavaFX)
* Part 14: Data processing, visualization, and final project (Asteroids)
